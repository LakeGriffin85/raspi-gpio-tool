# Changelog

## 2.7.0 – 2026-10-26

First public source release, with an independent repository history.

- Live 40-pin view, explicit activation and independent ownership of multiple pins.
- German and English UI, local preferences and an optional Gertboard module.
- Nonmodal selection windows; opening/cancelling lists does not change pins.
- Gertboard connector atlas and LED/button instructions.
- Separate base and Gertboard packages with deterministic builds and explicit file lists.
- Mock GPIO tests and optional native Tk interaction/layout tests.
