# External references

Runtime dependencies are installed from Raspberry Pi OS packages and are not
copied into this repository or the release archives:

- [guizero](https://lawsie.github.io/guizero/)
- [gpiozero](https://gpiozero.readthedocs.io/)
- [lgpio](https://abyz.me.uk/lg/py_lgpio.html)
- [Raspberry Pi GPIO documentation](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html#gpio)

The optional Gertboard schematic and explanations refer to the linked
[Gertboard user manual](https://www.farnell.com/datasheets/1683444.pdf) and the
manufacturer pages linked from each in-app region. The manual PDF and reference
photographs are not distributed here. Links do not change those materials' licences.
