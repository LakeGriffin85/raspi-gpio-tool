# Image provenance

- **app-screenshot.png** — application screenshot contributed by LakeGriffin85.
  It shows version 2.7.0 in English on a Raspberry Pi. It is an example of one
  machine's state, not a default pin configuration.
- **gertboard-on-pi.jpg** — hardware reference photograph contributed and approved
  for publication by LakeGriffin85. It shows physical placement of a legacy
  Gertboard above a Raspberry Pi 5, not a complete electrical wiring plan.
- **project-banner.svg**, **pin-orientation.svg**, **gertboard-map.svg** — native
  SVG documentation graphics. Pin and board diagrams use the same canonical
  models as the app and can be regenerated with `tools/render_docs_assets.py`.

The screenshot container was stripped of identifying metadata. The photograph
uses the camera-generated JPEG preview from the original RAW container, with
identifying metadata removed. Pixel data were checked to remain unchanged;
no generative reconstruction or retouching of components or wiring was used.
Original RAW files, EXIF/GPS records, private filenames and local source paths
are not distributed. The published project images use the repository MIT licence.
